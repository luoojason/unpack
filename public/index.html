Questions

    

      
Can I rebuild any game?
No. Use it on software you own or that is open source. Commercial games such as Elden Ring or Minecraft are compiled to native code or heavily protected, and rebuilding them would be piracy.

      
Why is the copy not identical to the original?
Compilers throw away comments, local variable names and formatting. No tool can bring those back, so the rebuilt code matches in behavior and structure, not in every character.

      
Is the OpenRA run live?
It is a recording of a real run: 2.5 minutes on a laptop, on OpenRA’s official compiled files, with the result saved. The same pipeline runs live on your own .NET files, minus the multi-assembly checks.

      
Does it run my file?
On the hosted version, no. Uploads are decompiled and rebuilt but never executed. The side-by-side play test runs only on the bundled demo.

      
What do I get in the download?
A zip with the recovered source files and a project file. Open it in Visual Studio or run dotnet build.

      
How is the score calculated?
Half comes from running both programs on the same inputs. The rest comes from how much of the true source and how many names were recovered. Without the true source, only the behavior part is scored.
